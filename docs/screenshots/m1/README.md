# M1 真实应用主题证据

应用与构建来源：`f9985d8be4fbbb0dbd7fc44ee5e248da14de0fc4`，干净工作区。`verification.json` 记录完整 lint、7 项类型项目、101 项行为测试和四个生产构建的真实退出码；`manifest.json` 和逐阶段清单记录实际 Electron 进程、构建及图片 SHA256。

35 张截图包括六页面×两尺寸12张、六主题设置6张、键盘焦点6张、原 green 与明确的自定义 fixture 2张、八次完整进程重启保持8张、自动主题配置色块1张。音频设备真实告警独立记为 observation。九个不同 Electron 进程顺序退出后复用同一个临时 profile；没有用页面 reload 代替应用重启。

这些图片在证据归档提交之前产生，因此来源 commit 指向实际被构建的源码提交。归档同时为取证工具相对期限改用单调时钟，应用源码与本组图片的构建保持一致；清单内 harness SHA256 保留当时的真实值，不冒称计时修复后的工具已生成这些图。最终 PR head 的 CI 会重新执行完整验证及35图矩阵，最新报告以该 CI artifact 为准。

测试使用临时空数据库与标记的自定义主题 fixture，外部网络禁止，没有个人账号或资料。只证明 Linux 云端应用与交互；Windows/macOS、系统音频输出、托盘、安装包和实际音乐服务仍需相应环境确认。
